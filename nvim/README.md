# NeoVim

Configuration for NeoVim.
* Sensible defaults
* lazy.nvim for plugin management
* Small rolling plugin set without pinned versions in this repo
* Curated tree-sitter parsers bootstrapped into an isolated runtime directory
* `./install nvim` offers to install `neovim` and `tree-sitter-cli` on macOS
* Mutable editor state, including Lazy's local lockfile, lives under Neovim's XDG state directory, not inside this repo
